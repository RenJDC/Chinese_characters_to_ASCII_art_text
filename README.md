# char2ascii

汉字 → ASCII 艺术字转换器。将任意汉字渲染为位图，再用 ASCII 字符密度映射输出。

## 原理

```
汉字字体渲染 → 4x 超采样位图 → Lanczos 缩放抗锯齿 → 灰度采样 → ASCII 密度映射 → 输出
```

用 Pillow 将汉字渲染为灰度图，每个像素的亮度值映射到不同视觉密度的 ASCII 字符上，亮区用稀疏字符（`.` ` `），暗区用密集字符（`@` `#`），从而在终端中还原汉字轮廓。

## 依赖

- Python 3
- Pillow

```bash
pip install Pillow
```

macOS 自带中文字体（PingFang），无需额外安装字体。

## 用法

### 命令行

```bash
# 单字转换
python3 char2ascii.py 龙

# 多字并排
python3 char2ascii.py "天地玄黄"

# 指定宽度
python3 char2ascii.py 龙 -w 60

# 方块字符风格
python3 char2ascii.py 龙 -c blocks

# 反色（黑底白字）
python3 char2ascii.py 龙 -i

# 调整字间距
python3 char2ascii.py "龙猫大战" -g 4

# 交互模式
python3 char2ascii.py
```

### 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `char` | 要转换的汉字（单个或多个） | 交互模式 |
| `-w, --width` | 输出宽度（字符数） | 40 |
| `-H, --height-ratio` | 高度比例 | 1.0 |
| `-c, --charset` | 字符集 | classic |
| `-f, --font` | 字体路径 | 系统中文字体 |
| `-i, --invert` | 反转明暗 | false |
| `-g, --gap` | 多字间距空格数 | 2 |
| `--list-charsets` | 列出可用字符集 | - |

### 字符集

| 名称 | 字符 | 特点 |
|------|------|------|
| `classic` | `@%#WMo=-~:. ` | 经典 ASCII，层次丰富 |
| `simple` | `@#=-. ` | 简洁，对比强烈 |
| `blocks` | `█▓▒░ ` | 方块字符，像素画风格 |
| `minimal` | `#=-. ` | 极简，快速预览 |

也可以直接传入自定义字符集字符串（从密到疏排列）：

```bash
python3 char2ascii.py 龙 -c "█▓▒░ "
```

## Python 调用

```python
from char2ascii import convert, batch_convert

# 单字
print(convert("龙", width=40, charset_name="classic"))

# 多字并排
print(batch_convert("龙猫", width=30, charset_name="blocks", gap=3))
```

## 注意事项

- 笔画简单的字（一、大、口）效果好，笔画复杂的字（赢、齉）会丢失细节
- 宽度越大细节越多，但渲染越慢
- macOS 默认使用 PingFang 字体，Linux/Windows 需指定中文字体路径

# char2ascii

汉字 → ASCII 艺术字转换器。将任意汉字渲染为位图，再用 ASCII 字符密度映射输出。

## 原理

```
汉字字体渲染 → 4x 超采样位图 → Lanczos 缩放抗锯齿 → 灰度采样 → ASCII 密度映射 → 输出
```

用 Pillow 将汉字渲染为灰度图，每个像素的亮度值映射到不同视觉密度的 ASCII 字符上，亮区用稀疏字符（`.` ` `），暗区用密集字符（`@` `#`），从而在终端中还原汉字轮廓。

## 依赖

- Python 3
- Pillow

```bash
pip install Pillow
```

### 字体

项目自带 `fonts/` 目录，内置 Noto Sans CJK（Google 开源，SIL OFL 许可），开箱即用无需配置。

如需使用其他字体：
- 放入 `fonts/` 目录即可自动识别（支持 `.ttf` `.otf` `.ttc`）
- 或用 `-f /path/to/font.ttf` 手动指定

查找优先级：`-f` 参数 → `fonts/` 目录 → 系统字体

## 用法

### 命令行

```bash
# 单字转换
python3 char2ascii.py 龙

# 多字并排
python3 char2ascii.py "天地玄黄"

# 指定宽度
python3 char2ascii.py 龙 -w 60

# 方块字符风格
python3 char2ascii.py 龙 -c blocks

# 反色（黑底白字）
python3 char2ascii.py 龙 -i

# 调整字间距
python3 char2ascii.py "龙猫大战" -g 4

# 交互模式
python3 char2ascii.py
```

### 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `char` | 要转换的汉字（单个或多个） | 交互模式 |
| `-w, --width` | 输出宽度（字符数） | 40 |
| `-H, --height-ratio` | 高度比例 | 1.0 |
| `-c, --charset` | 字符集 | classic |
| `-f, --font` | 字体路径 | 系统中文字体 |
| `-i, --invert` | 反转明暗 | false |
| `-g, --gap` | 多字间距空格数 | 2 |
| `--list-charsets` | 列出可用字符集 | - |

### 字符集

| 名称 | 风格 | 特点 |
|------|------|------|
| `classic` | `@%#WMo=-~:. ` | 经典 ASCII，层次丰富 |
| `simple` | `@#=-. ` | 简洁，对比强烈 |
| `blocks` | `█▓▒░ ` | 方块像素风 |
| `minimal` | `#=-. ` | 极简 |
| `3d` | `@%#WMBRW$&8XOZ...` | 3D 立体阴影 |
| `italic` | `///\\\|||;;;` | 斜线流动风 |
| `bold` | `█▇▆▅▄▃▂▁ ` | 粗块渐变 |
| `thin` | `─━═║┃┆┇┊┋ ` | 细线几何 |
| `gothic` | `▓█▄▀▌▐■□◆◇●○ ` | 哥特复古 |
| `graffiti` | `@%#MW&8B$S#%W@ ` | 涂鸦艺术 |
| `gradient` | `@%#WMo=-~^:;,. ` | 平滑渐变灰阶 |
| `braille` | `⣿⣷⣯⣟⡿⢿...` | Braille 点阵，细节最丰富 |
| `halfblock` | `▀▄█▓▒░ ` | 半块像素 |
| `box` | `█▓▒░╔╗╚╝═║...` | 制表符几何 |
| `dots` | `●◉◎∘○○∘◎◉● ` | 圆点矩阵 |
| `stars` | `★☆✦✧✪✫✬✭✮✯ ` | 星号装饰 |

也可以直接传入自定义字符集字符串（从密到疏排列）：

```bash
python3 char2ascii.py 龙 -c "█▓▒░ "
```

## Python 调用

```python
from char2ascii import convert, batch_convert

# 单字
print(convert("龙", width=40, charset_name="classic"))

# 多字并排
print(batch_convert("龙猫", width=30, charset_name="blocks", gap=3))
```

## 交互模式

运行 `python3 char2ascii.py` 进入交互模式，支持实时切换设置：

```
>>> /help        # 查看所有命令
>>> /c braille   # 切换风格
>>> /w 60        # 调整宽度
>>> /i           # 反色
>>> /r 1.5       # 调整高度比
>>> /g 4         # 调整间距
>>> /s           # 查看当前设置
>>> /l           # 列出所有风格
>>> 龙           # 输入汉字即转换
>>> q            # 退出
```

## 注意事项

- 笔画简单的字（一、大、口）效果好，笔画复杂的字（赢、齉）会丢失细节
- 宽度越大细节越多，但渲染越慢
- 如自动检测不到字体，用 `-f /path/to/font.ttf` 手动指定
